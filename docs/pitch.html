The decision

Can a firmware team trust the patch?

A telemetry parser can pass a whole-frame test and still lose samples when serial reads split a frame. A passing public test gives the reviewer only part of the evidence.

Two agents

Inspect ReAct and smolagents ToolCallingAgent receive the same source, issue, tools and limits.

Two tasks

Recover partial UART frames or retain the newest four samples through ring-buffer wraparound.

Experiment design

Repeat each disruption

Clean

Broken tool

Model outage

Return a controlled HTTP 503 and follow the fallback through Bifrost.

Misleading fixture

Verification

Grade the final source independently

The host sends test inputs into an isolated GCC container and compares output with expectations held outside it.

Calibration

On both tasks the starter fails, the complete repair passes, and a partial repair passes public tests while failing reserved cases.
