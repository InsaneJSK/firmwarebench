How to run your own benchmark

FirmwareBench is a self-hosted benchmarking platform. Install it from the repository, choose a supported model route through Bifrost, and configure your own provider credentials locally. Live experiments run the agent worker and Docker verifier in your environment.

This public evidence explorer needs no API key and does not launch jobs. Opening an export reads the file in your browser without uploading it.
